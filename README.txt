RUKKIES BEAUTYWORLD WEBSITE

Files:
- index.html: website structure and content
- styles.css: responsive styling
- script.js: mobile navigation and WhatsApp appointment form
- assets/: supplied logo and hairstyle photos

PREVIEW / RUN:
Open index.html in a browser. For a local server, open a terminal in this folder and run:
python -m http.server 8000
Then visit http://localhost:8000

NOTES:
- Booking form opens WhatsApp with the submitted details; the salon must confirm the appointment.
- Prices are displayed as ₦20,000 guide prices and should be confirmed with the salon.
- Map uses the supplied address: 177, Oduyebo, Shagamu Road, Ikorodu, Lagos.
- Instagram and TikTok links use the supplied handles.
